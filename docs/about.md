# About the author

**Geovana Neves** is an aerodynamics and flight dynamics engineer, and a researcher at Instituto Tecnologico de
Aeronautica (ITA), in collaboration with TU Delft, on propeller-airframe integration and stability and control
sizing.

| Project | What it is |
